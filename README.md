# Database Systems Design & Modelling

## Project Overview
An academic database design and modelling project completed as part of the Database Systems module at the University of Westminster.

The coursework explores conceptual and logical database modelling for residential property management and tour booking scenarios.

## Project Components
- Evaluated an AI-generated Enhanced Entity-Relationship Diagram (EERD).
- Designed a conceptual EERD for a residential management system.
- Created a data dictionary documenting entities, relationships and multiplicities.
- Developed a logical ERD for a tour booking system.
- Applied relational mapping rules, including primary keys, foreign keys and specialisation.
- Compared relational and NoSQL database approaches for booking consistency, concurrency and scalability.

## Technologies & Concepts
- Database Design
- UML and ER Diagrams
- Relational Data Modelling
- Primary and Foreign Keys
- PostgreSQL and MongoDB (research and comparison)

## Skills Demonstrated
- Database architecture analysis
- Logical and conceptual modelling
- Data integrity and relationship design
- Technical documentation
- Critical evaluation of database technologies
